# ROS 学习速查站 · 部署说明

这是一个**纯静态网站**，没有任何后端、不需要安装、不需要“构建步骤”。把整个文件夹传到任意静态托管上就能上线。

## 文件夹内容

| 文件 | 说明 |
|------|------|
| `index.html` | 首页（入口） |
| `commands.html` | 命令速查字典（Ubuntu + ROS2） |
| `cpp.html` | C++ 语法字典（新手版） |

三页互相有顶部导航，点一下即可切换。

---

## 方式一：Netlify 拖拽部署（最简单，约 1 分钟）

1. 浏览器打开 **https://app.netlify.com/drop**
2. 把 **整个 `ros-study-site` 文件夹**拖进页面
3. 等几秒，出现一个网址，形如 `https://随机名.netlify.app` —— 这就是你的网站
4. 想更新内容：重新拖一次覆盖即可

> 免费、无需信用卡。不注册也能先试；注册后可以改名、保留站点。

---

## 方式二：Cloudflare Pages

1. 登录 **https://dash.cloudflare.com**
2. 左侧 **Workers & Pages → Create → Pages → Upload assets**（上传已有资源）
3. 项目名随意填，例如 `ros-study-site`
4. 把文件夹里的三个 `.html` 拖进去（或直接选文件夹）→ **Deploy**
5. 得到网址 `https://项目名.pages.dev`

> 也可以关联 GitHub 仓库实现“推送即自动部署”，但首次上手用上面的上传方式最快。

---

## 注意事项

- **首页文件名必须是 `index.html`**，且和另外两个 `.html` 放在**同一层**。不要多套一层文件夹（不能出现 `ros-study-site/ros-study-site/index.html`），否则打开会是空目录。
- 平台若问“构建命令 / 输出目录”，**留空**即可（没有构建过程）。
- 三个页面都是**自包含**的，所以你甚至可以只传其中一页；但作为一个“站”，建议三个一起传。

## 以后更新

- 你把新的课件发给我 → 我重新生成对应页面 → 你把新文件夹**整个重新上传覆盖**即可。

## 手机上看

部署后用手机浏览器打开网址就能用，也可以“添加到主屏幕”，像 App 一样一点即开。
